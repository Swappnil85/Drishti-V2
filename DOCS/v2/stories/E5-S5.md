## Overview
Enhanced QA reset controls in Settings screen to provide essential tools for testing onboarding flows and resetting app state during QA cycles.

## Acceptance Criteria ✅
- [x] Add "Reset Onboarding (QA only)" → clears onboarding completion flag
- [x] Add "Reset ALL Preferences (QA only)" → clears all local preferences  
- [x] Both under a dedicated QA section in Settings
- [x] Must work reliably on Web + Expo Go

## Technical Implementation

### QA Section
- Dedicated "QA Tools" section in Settings screen
- Proper styling with destructive button appearance
- Clear visual separation from other settings

### Reset Onboarding
- Clears `onboarding.completed`, `onboarding.step`, `onboarding.progress`
- Shows confirmation dialog before action
- Navigates user back to onboarding flow
- Logs telemetry event: `qa_reset_onboarding`

### Reset ALL Preferences
- Clears all preferences including:
  - Onboarding state
  - Theme preferences
  - Privacy settings
  - Security settings
- Shows confirmation dialog with warning
- Logs telemetry event: `qa_reset_all_preferences`

### Error Handling
- Proper try/catch blocks around storage operations
- User feedback via Alert dialogs
- Graceful handling of storage failures
