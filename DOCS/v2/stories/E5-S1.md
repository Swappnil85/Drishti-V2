**Status:** DONE ✅ (2025-08-18) - [PR #TBD](https://github.com/Swappnil85/Drishti-V2/pull/TBD)

## Overview
Implemented onboarding gate in the root layout to ensure users complete onboarding before accessing the main app. The gate redirects users to onboarding if the completion flag is missing.

## Acceptance Criteria ✅
- [x] Move onboarding gate into `apps/mobile-v2/app/_layout.tsx` (Expo Router entry)
- [x] If `onboarding.completed` flag is missing → `<Redirect href="/onboarding/welcome" />`
- [x] If completed → `<Slot />` (Tabs)
- [x] Proper error handling and loading states

## Technical Implementation

### Onboarding Gate Logic
- **Location**: `app/_layout.tsx` - Expo Router root layout
- **Storage Check**: Reads `onboarding.completed` from AsyncStorage
- **Redirect Logic**: Uses `<Redirect href="/onboarding/welcome" />` for incomplete onboarding
- **Tab Access**: Uses `<Slot />` to render tab navigation when onboarding is complete

### Error Handling
- Graceful handling of storage read failures
- Loading state while checking onboarding status
- Fallback to onboarding screen on errors

### Navigation Flow
1. App starts → `_layout.tsx` loads
2. Check `onboarding.completed` in AsyncStorage
3. If missing/false → Redirect to `/onboarding/welcome`
4. If true → Render main app tabs via `<Slot />`
